# Quiet Giving

Build the user's Midnight donation application, matching BallotLab, Agent AI Wallet and ReviewLab. Publish source and frontend to the IBKR-BouncyBot GitHub account and ordinary GitHub Pages. This explicit destination takes precedence over Sites hosting defaults.

Use the public alias IBKR-BouncyBot in source attribution, Git metadata and public artifacts. Do not publish personal names, account credentials, local usernames or absolute personal paths.

Keep browser demonstrations, generated Compact execution, cryptographic proof generation and accepted Preview transactions distinct. Never substitute fabricated proofs, receipts or balances for real evidence. No mainnet operations. A testnet donation uses valueless test tokens.

Donor identity and private receipt openings must never be submitted in public ledger state. The recipient sees receipt of funds, the authority demo receives only a deliberately shared disclosure. The browser authority is an illustrative verifier, not an actual government endpoint. A self-entered taxpayer identifier is not verified legal identity and a cryptographic proof is not official tax acceptance.

Use Compact 0.31.1, runtime 0.16.0, Midnight.js 4.1.1 and DApp Connector API 4 as in ReviewLab. Compile with the official compiler, use actual generated artifacts, commit a real dependency lockfile, and validate the browser journey. Preserve external package licenses and use the family's PolyForm Noncommercial license.

Treat imported receipt JSON as untrusted; validate bounds and commitments and render text safely. Private state must remain in memory or be explicitly encrypted/exported. Keep donor secrets out of public exports and logs. Do not modify sibling projects.
