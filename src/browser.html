Privacy, receipts and what this demo proves

The browser demo executes actual generated Midnight Compact contract code and uses its cryptographic commitment functions. It does not create a zero-knowledge proof, spend tokens or submit a transaction. The displayed token amounts illustrate the result of local contract execution.

The authority demonstration verifies a private receipt opening against this session’s local record. A saved file alone does not establish a real donation, a verified taxpayer identity, an official recipient or tax deductibility. Refreshing or resetting creates a new local session. Private receipt files are unencrypted.

The recipient, donor and authority are interface perspectives in one trusted browser process, not separate security boundaries. The Preview client uses network-confirmed commitments; actual tax-authority integration and legal acceptance remain separate work.
